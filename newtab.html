    通用

    控制点击站点卡片时的打开方式。

    勾选后点击站点在当前标签页跳转；取消勾选则在新标签页打开。

    数据存储位置

    可多选：数据会同时写入所有勾选的位置。读取按 云端 -> 同步 -> 本地 优先。本地 IndexedDB 容量可达磁盘级；同步约 100KB 限制；WebDAV/Gist 为云端跨设备，勾选后在「云端配置」页填写凭证。

    云端凭证仅保存在本机 chrome.storage.local，不会上传到其他位置。WebDAV 与 GitHub Gist 分别独立配置。

    未启用任何云端存储。可先在「数据存储」中勾选 WebDAV 云端或 GitHub Gist。

    数据备份

    导出当前所有分类和站点，或从 JSON 文件恢复。

    自动备份

    自动保存一份 JSON 到下载目录。可填写相对路径，如 backups/c-home.json。
